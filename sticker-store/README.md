# لزّقها: متجر ملفات ستيكرز PDF

صفحة متجر واحدة (`index.html`) بواجهة ثلاثية الأبعاد، تعرض ١٦ ملف ستيكرز PDF مع معاينة صفحات وسلة وباقة كاملة.

- صور الأغلفة والمعاينات في `assets/` (أول ٣ صفحات من كل ملف، بدقة منخفضة).
- ملفات PDF الأصلية **ليست** في المستودع.
- الدفع غير مربوط بعد: زر «إتمام الشراء» يعرض رسالة تأكيد فقط.

للتشغيل محلياً (الواجهة ثلاثية الأبعاد تحتاج خادم، ما تشتغل من `file://`):

```
cd sticker-store && python3 -m http.server 8000
```
