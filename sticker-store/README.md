# لزّقها: متجر ملفات ستيكرز PDF

صفحة متجر واحدة (`index.html`) بواجهة ثلاثية الأبعاد، تعرض ١٥ ملف ستيكرز PDF مع معاينة صفحات وسلة وباقة كاملة.

- صور الأغلفة والمعاينات في `assets/` (أول ٣ صفحات من كل ملف، بدقة منخفضة).
- ملفات PDF الأصلية **ليست** في المستودع.
- الدفع غير مربوط بعد: زر «إتمام الشراء» يعرض رسالة تأكيد فقط.

للتشغيل محلياً (الواجهة ثلاثية الأبعاد ولحظة التمرير تحتاج خادم، ما تشتغل من `file://`). مكتبة Three.js محفوظة داخل `vendor/` فما تحتاج إنترنت لها:

```
cd sticker-store && python3 -m http.server 8000
```
