# awesome-design-md

Source: https://github.com/VoltAgent/awesome-design-md (MIT, see `LICENSE`).

Each folder in `design-md/<site>/` holds a `DESIGN.md` with the same sections: visual theme,
color palette and roles, typography hierarchy, components and states, layout and spacing,
depth and elevation, do's and don'ts, responsive behavior, and an agent prompt guide.

## How to use

1. List the options: `ls design-md/`.
2. Read one or two files close to the brief (for a shop: `shopify`, `nike`, `apple`, `airbnb`,
   `starbucks`, `pinterest`).
3. Use them as a template for structure and level of detail. Write this project's own
   `DESIGN.md` at the project root with this project's palette, fonts and rules.
4. Do not copy another brand's identity (colors, logo, type pairing) wholesale. The upstream repo
   states it does not own these visual identities; they are references only.
